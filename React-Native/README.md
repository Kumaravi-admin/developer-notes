## Quick Start

Install Expo CLI:

```bash
npm install -g expo-cli
```

Create a new project:

```bash
npx create-expo-app my-app
```

Start the development server:

```bash
cd my-app

npm start
```

Run on Android:

```bash
npm run android
```

Run on iOS:

```bash
npm run ios
```
